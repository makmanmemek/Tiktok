JACKSALLAS — PAKET DEPLOY VERCEL

Isi:
- index.html       : aplikasi video pendek
- admin/index.html : dashboard admin demo di /admin
- vercel.json      : konfigurasi static deployment dan security headers

Deploy:
1. Ekstrak ZIP ini.
2. Masukkan folder jacksallas-vercel ke repository GitHub milikmu.
3. Import repository tersebut dari dashboard Vercel.
4. Framework Preset: Other.
5. Build Command: kosongkan.
6. Output Directory: . (root project).
7. Deploy.
8. Di Project Settings > Domains, pastikan domain jacksallas.vercel.app ditambahkan/terpasang.

Catatan penting:
Ini adalah prototype frontend. Data pengguna, login, upload permanen, moderasi, dan admin belum terhubung ke backend/database. Upload video pada demo hanya memakai URL lokal browser dan tidak membuat video tersedia untuk pengunjung lain. Jangan gunakan dashboard demo sebagai panel admin produksi atau memasukkan data pribadi sungguhan.
